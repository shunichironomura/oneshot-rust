あるお店には、注文がテキストで届きます。1 行に 1 件の注文が書かれています。
有効な注文を読み取る関数と、ある商品が合計でいくつ注文されたかを求める関数を実装してください。

```rust
pub fn parse_orders(text: &str) -> Vec<(u32, &str)>
pub fn total_quantity(text: &str, item: &str) -> u32
```

- `text` は `str::lines` で行に分けます（行の終わりは `\n` または `\r\n` です）。
- `#` からはコメントです。`#` とその行の残りの部分は無視します。
- 行の残った部分が**ちょうど 2 つ**の単語 `COUNT ITEM` からなるとき、その行は有効な注文です。
  単語は空白（スペースやタブ。いくつ続いても構いません）で区切られます。行頭と行末の空白は関係ありません。
- `COUNT` は `str::parse::<u32>` で解釈できる文字列で、値が `0` でないものに限ります。
  たとえば `7`、`+7`、`007` はどれも 7 を表しますが、`0`、`-7`、`7.0`、`seven`、
  `4294967296`（`u32` に収まらない）は無効です。
- `ITEM` はどんな単語でも構いません。
- 有効な注文でない行は、空行やコメントだけの行も含めて、何も言わずに読み飛ばします。
- `parse_orders` は、有効な注文それぞれの `(count, item)` の組を、行の順に返します。
  各 `item` は `text` の一部を指すスライスです（コピーではありません）。
- `total_quantity` は、商品名が `item` と完全に一致する有効な注文について、個数の合計を返します。
  該当する注文がなければ `0` です。大文字と小文字は区別します。`Cups`、`cup`、`teacups` は
  `cups` と一致しません。合計は `u32` に収まるものとします。

### 例

```rust
let text = "3 cups\n# note\n\n 2 pens # red\nx cups\n0 pens\n4 big cups\n5 cups";

parse_orders(text)            // [(3, "cups"), (2, "pens"), (5, "cups")]
total_quantity(text, "cups")  // 8
```

`x cups` は個数が数として読めず、`0 pens` は個数が 0 で、`4 big cups` は単語が 3 つあるので、
これらの行は読み飛ばします。
