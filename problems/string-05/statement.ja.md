`initials` は、フルネームを頭文字に縮めます。

```rust
pub fn initials(full_name: &str) -> String
```

- `full_name` の各単語の最初の文字の後ろに `.` を付け、順につなげて返します。
- 単語は 1 個以上の空白文字（スペース、タブ、改行）で区切られます。先頭と末尾の空白文字は無視します。
- 文字はそのまま使い、大文字・小文字は変えません。単語は ASCII の英字に限らず、どの Unicode 文字で
  始まっても構いません。
- 単語が 1 つもなければ `""` を返します。

シグネチャは変えないでください。

### 例

- `initials("Grace Brewster Hopper")` は `"G.B.H."` です。
- `initials("émile zola")` は `"é.z."` です。
