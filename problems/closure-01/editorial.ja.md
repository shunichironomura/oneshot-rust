キャプチャした変数を書き換えるクロージャは `FnMut` を実装します。カウンターに必要なのはこれです。
このクロージャは `make_counter` の呼び出しが終わった後も使われるので、`step` と `current` を**所有**しなければなりません。
`move` がないと、関数から戻った時点でなくなるローカル変数を借用するだけになり、コンパイルエラーになります。

戻り値の位置に `impl FnMut() -> u32` と書くと、名前のないクロージャの型を `Box` に包まずにそのまま返せます。

### 別解

合計の代わりに呼び出し回数を数えても、イテレータに状態を持たせても書けます。イテレータも `move` でキャプチャします。
`next()` には `&mut` が必要なので、このクロージャもやはり `FnMut` です。

```rust
pub fn make_counter(step: u32) -> impl FnMut() -> u32 {
    let mut multiples = (1..).map(move |k| k * step);
    move || multiples.next().unwrap()
}
```

`Box<dyn FnMut() -> u32>` を返す方法もありますが、与えられたシグネチャと合わないうえ、メモリ確保と動的呼び出しのコストがかかります。
