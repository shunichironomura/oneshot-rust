要素を複製（`Clone`）できる**すべてのイテレータ**に、`pairs` メソッドを追加してください。`pairs` は、
各要素をその直後の要素と組にして返す新しいイテレータを返します。

```rust
pub trait Pairs: Iterator + Sized {
    fn pairs(self) -> PairsIter<Self>;
}
```

`template.rs` には、トレイト、`PairsIter` 構造体、各 `impl` の骨組みがあります。本体を埋め、必要に応じて
`PairsIter` にフィールドを追加してください。トレイトは変更しないでください。

- 要素が 2 個未満のイテレータからは、組は 1 つも出てきません。
- `pairs` は遅延評価にしてください。`(0..)` のような無限のイテレータでも動く必要があります。

### 例

`vec![1, 2, 3, 4].into_iter().pairs()` は `(1, 2)`、`(2, 3)`、`(3, 4)` を返します。
`"abc".chars().pairs()` は `('a', 'b')`、`('b', 'c')` を返します。
