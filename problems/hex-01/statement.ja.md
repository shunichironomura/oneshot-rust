Web では、色を `#ff8800` のような 16 進数のカラーコードで書くことがよくあります。
カラーコードを読み取る関数と、書き出す関数を実装してください。

```rust
pub fn parse_hex_color(s: &str) -> Option<[u8; 3]>
pub fn to_hex(rgb: [u8; 3]) -> String
```

ここで「16 進数字」とは、ASCII 文字の `0` から `9`、`a` から `f`、`A` から `F` のことで、
0 から 15 の値を表します（`a` と `A` は 10、`f` と `F` は 15）。大文字と小文字は自由に混ぜて構いません。

- `parse_hex_color` は、色 `s` の赤・緑・青の値をこの順に返します。受け付ける形は次の 2 つです。
  - `#` の後に 16 進数字が 6 個続く形（`rrggbb`）。各チャンネルは 2 桁の 16 進数なので、
    `#0A0b0C` は `[10, 11, 12]` です。
  - `#` の後に 16 進数字が 3 個続く形（`rgb`）。各数字 `d` は 2 桁の `dd` を表すので、
    `#f80` は `#ff8800`、つまり `[255, 136, 0]` です。
- `s` は全体がちょうどこのどちらかの形でなければならず、前にも途中にも後ろにも余計なものがあっては
  いけません。それ以外はすべて `None` になります。たとえば、先頭に `#` がない、`#` がもう 1 つある、
  数字の個数が違う（CSS には透明度付きの 4 桁と 8 桁の形もありますが、ここでは受け付けません）、
  どこかに空白がある（`s` の前後の空白は取り除きません）、
  そのほかの 16 進数字ではない文字がある（ASCII かどうかにかかわらず）、といった場合です。
- `parse_hex_color` は、どんな `s` に対してもパニックしてはいけません。
- `to_hex` は、`parse_hex_color` で読み取ると `rgb` に戻る最も短いカラーコードを返します。
  英字は小文字で書きます。
  - 3 つのチャンネルのどれも、上の桁と下の桁が同じ（`0x00`, `0x11`, …, `0xff` のどれか）なら、
    3 桁の形にします。`[255, 136, 0]` は `"#f80"` になります。
  - そうでなければ、どのチャンネルもちょうど 2 桁で書いた 6 桁の形にします。
    `[255, 8, 0]` は `"#ff0800"` になります。

### 例

| 呼び出し | 結果 |
| --- | --- |
| `parse_hex_color("#0A0b0C")` | `Some([10, 11, 12])` |
| `parse_hex_color("#f80")` | `Some([255, 136, 0])` |
| `parse_hex_color("ff8800")` | `None`（`#` がない） |
| `parse_hex_color("#ff80")` | `None`（4 桁） |
| `to_hex([255, 8, 0])` | `"#ff0800"` |
| `to_hex([255, 136, 0])` | `"#f80"` |
