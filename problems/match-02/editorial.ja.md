単語を `Vec<&str>` に集め、`words.as_slice()` で `match` します。**スライスパターン**を使うと、単語の数と、
決まった単語であることを同時に確かめられます。`["move", x, y]` は `"move"` で始まるちょうど 3 単語にだけマッチし、
残りの 2 つを束縛します。単語が多すぎたり足りなかったりする入力は、長さを確かめなくても `_ => None` に落ちます。

- `rest @ ..` は残りの単語を部分スライスとして束縛します。**ガード** `if !rest.is_empty()` で `say` だけの行を除き、
  `rest.join(" ")` で文を組み立て直します。
- `"quit" | "exit"` は、スライスパターンの中に書いた or パターンです。
- `Ok(n @ 1..=60)` は、解析した数が範囲内のときだけマッチし、その数を `n` に束縛します。
- `Option` を返す関数の中では、`x.parse().ok()?` で解析エラーをすぐ `None` にできます。

### 別解

`say` の分岐は、ガードを使わずにパターンだけで「1 単語以上」を表すこともできます。

```rust
["say", first, rest @ ..] => {
    let mut text = first.to_string();
    for w in rest {
        text.push(' ');
        text.push_str(w);
    }
    Some(Command::Say(text))
}
```

方角も `["go", "north"] => Some(Command::Move { x: 0, y: 1 })` のように別々の分岐で書けます。
分岐は増えますが、1 つの分岐が 1 つの規則としてそのまま読めます。
