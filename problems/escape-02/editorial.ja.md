`str` は常に正しい UTF-8 なので、`str` のリテラルで使える `\x` エスケープは `\x7F` までです。`\u{89}` は
コンパイルが通りますが、これは文字 U+0089 で、UTF-8 では `0xC2 0x89` の 2 バイトになるため、
結果は 9 バイトになってしまいます。バイト文字列 `b"..."` は文字ではなくバイトの並びで、
`\x00` から `\xFF` まで書けます。型は `&'static [u8; 8]` で、返り値の型 `&'static [u8]` に型強制されます。
`.as_bytes()` も消してください。これは `str` のメソッドで配列にはないので、`b"...".as_bytes()` は
コンパイルが通りません。

### 別解

バイトは `u8` リテラルの配列でも書けます。`b'P'` は ASCII 文字 `P` のバイトです。定数だけからなる配列に
`&` を付けると `'static` な値に昇格されるので、`&'static [u8]` として返せます。

```rust
pub fn png_magic() -> &'static [u8] {
    &[0x89, b'P', b'N', b'G', b'\r', b'\n', 0x1A, b'\n']
}
```

生文字列とバイト文字列は組み合わせられます。`br"C:\new"` はエスケープのないバイト文字列です。
