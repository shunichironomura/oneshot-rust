プログラム全体で共有する文字列表（インターナ）です。異なる文字列ごとに番号（ID）を割り当てます。
プログラムのほかの部分は、文字列の代わりに小さな番号を保存したり比較したりでき、必要なときに
文字列に戻せます。

```rust
pub fn intern(s: &str) -> u32;
pub fn resolve(id: u32) -> Option<String>;
pub fn interned_count() -> usize;
pub fn intern_calls() -> usize;
```

- `intern(s)` は `s` の ID を返します。初めて登録される文字列には、まだ使われていない次の ID を
  割り当てます。ID は、文字列が初めて登録された順に `0`、`1`、`2`、... です。等しい文字列を
  もう一度登録すると、同じ ID を返します。
- 文字列は完全一致で比較します。大文字と小文字は区別し、前後の空白も取り除きません。空文字列を
  含め、どんな文字列でも登録できます。
- `resolve(id)` は ID が `id` の文字列を返します。その ID がまだ割り当てられていなければ `None` を
  返します。
- `interned_count()` はこれまでに登録された異なる文字列の数を返します。`intern_calls()` は
  これまでに `intern` が呼ばれた回数の合計を返します。登録済みの文字列での呼び出しも数えます。
  `resolve` と `interned_count` は、どちらの数も変えません。
- 表はプログラム全体で 1 つだけで、プログラムが終わるまで保持されます。これらの関数は複数の
  スレッドから同時に呼ばれることがあり、すべてのスレッドが同じ表を共有します。あるスレッドで
  返された ID は、どのスレッドでも同じ文字列に戻ります。複数のスレッドが同じ文字列を同時に
  登録しても、ID は 1 つだけです。割り当て済みの ID は、常にちょうど `0..interned_count()` です。

4 つの公開関数のシグネチャは変えないでください。それ以外（非公開の static、`use` 宣言、関数の本体）は
変更して構いません。

### 例

まだ何も登録していないプログラムでは、次のようになります。

```rust
intern("apple");  // 0
intern("pear");   // 1
intern("apple");  // 0（登録済み）
resolve(1);       // Some("pear")
resolve(2);       // None
interned_count(); // 2
intern_calls();   // 3
```
