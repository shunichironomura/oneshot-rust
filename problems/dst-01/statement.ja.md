次の 3 つの関数の本体はすでに書かれていますが、どのシグネチャも 1 つの具体的な型しか
受け取らないため、テストハーネス（`tests.rs` タブ）がコンパイルできません。ハーネスがコンパイルでき、
テストに通るように、**シグネチャだけ**を書き換えてください。本体は変更しないでください。

```rust
pub fn byte_size(x: &u64) -> usize
pub fn show_pair(a: &str, b: &str) -> String
pub fn share(b: Box<i32>) -> Rc<i32>
```

- `byte_size` は、`x` が指す値の大きさ（バイト数）を `std::mem::size_of_val` で求めて返します。
  文字列スライスなら UTF-8 でのバイト長、スライスなら要素数と要素 1 つの大きさの積です。
  ハーネスは、数値、配列、文字列スライス（`&str`）、スライス（`&[T]`）、
  トレイトオブジェクト（`&dyn Debug`）、ハーネス独自の型 `Rgb`（`derive` も `impl` も
  1 つもありません）の値への参照を渡します。
- `show_pair` は `a` と `b` を `{:?}` で書式化し、`" & "` でつなげます。2 つの引数の型は
  違っていてもかまいません。ハーネスは、数値、文字列スライス、スライス、
  トレイトオブジェクト（`&dyn Debug`）への参照を渡します。
- `share` は `Box` の中の値を新しい `Rc` に移します。ハーネスは `Box<i32>` のような普通の値の
  `Box` のほか、`Box<str>`、ボックス化したスライス（`Box<[T]>`）、ボックス化したクロージャ
  （`Box<dyn Fn(i32) -> i32>`）を渡し、それぞれの結果を同じ型の `Rc`（`Rc<i32>`、`Rc<str>`、
  `Rc<[T]>`、`Rc<dyn Fn(i32) -> i32>`）として使います。

ハーネスのローカル変数を借用している引数もあります。

### 例

```rust
byte_size("héllo")            // 6（"é" は 2 バイト）
byte_size(&[1u16, 2, 3][..])  // 6
byte_size(&7u64)              // 8

show_pair("x", &[1, 2][..])   // "\"x\" & [1, 2]"
show_pair(&5, "y")            // "5 & \"y\""

let s: Rc<str> = share(Box::<str>::from("abc"));
let v: Rc<[i32]> = share(vec![1, 2].into_boxed_slice());
let n: Rc<i32> = share(Box::new(5));
```
