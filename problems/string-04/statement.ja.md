狭い欄に表示するファイル名や長い ID は、末尾だけを残して短くすることがよくあります。
文字列の末尾の文字だけを残す関数 `last_chars` を実装してください。

```rust
pub fn last_chars(s: &str, n: usize) -> &str
```

ここでの「文字」は Rust の `char`（Unicode スカラー値）です。たとえば `"e\u{301}"`
（`e` の後に結合用のアクセント記号が続く）は 2 文字と数えます。

- `last_chars` は `s` の末尾の `n` 文字を返します。`s` が `n` 文字以下なら `s` 全体を返します。
- 新しい文字列や文字列リテラルではなく、`s` 自身の一部、つまり `s` の末尾で終わるスライスを返します。
  結果が空のときも同じです。テストでは、返したスライスがどこを指しているかも確認します。
- `n` は、0 や `s` の長さより大きい値も含めて、どんな値も取り得ます。

### 例

`last_chars("日本語です", 2)` は `"です"` です。
