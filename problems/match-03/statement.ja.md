関数 `quadrant` は、`match` を使って点が平面のどこにあるかを判定します。

```rust
pub fn quadrant(x: i32, y: i32) -> &'static str;
```

- `quadrant` は、`x > 0` かつ `y > 0` なら `"I"`、`x < 0` かつ `y > 0` なら `"II"`、`x < 0` かつ `y < 0` なら
  `"III"`、`x > 0` かつ `y < 0` なら `"IV"` を返します。
- 軸の上の点はどの象限にも入りません。`(0, 0)` は `"origin"`、それ以外で `x == 0` の点は `"y-axis"`、
  それ以外で `y == 0` の点は `"x-axis"` です。

シグネチャは変えないでください。

### 例

| 呼び出し | 結果 |
| --- | --- |
| `quadrant(-2, 5)` | `"II"` |
| `quadrant(0, -3)` | `"y-axis"` |
