文字列 `s` の各単語について、先頭の 1 文字を大文字にした文字列を返してください。

```rust
pub fn capitalize_words(s: &str) -> String
```

- 単語とは、空白文字以外の文字が連続した部分です。空白文字（スペース、タブ、改行）はそのまま残します。
- 変えるのは各単語の先頭の 1 文字だけです。2 文字目以降は、すでに大文字であってもそのままにします。
- 大文字への変換は Unicode の規則に従い、どの言語の文字にも対応します。1 文字が複数の文字になることもあります
  （`'ß'` は `"SS"` になります）。大文字のない文字はそのままです。

### 例

| 入力 | 出力 |
| --- | --- |
| `"hello world"` | `"Hello World"` |
| `"élan vital"` | `"Élan Vital"` |
