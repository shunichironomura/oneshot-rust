サイズに上限のある欄に保存する文字列は、途中で切り詰めなければならないことがよくあります。
文字を途中で分断せずに、文字列をバイト数の上限まで短くする 2 つの関数を実装してください。

```rust
pub fn truncate_bytes(s: &str, max: usize) -> &str
pub fn ellipsize(s: &str, max: usize) -> String
```

バイト数は UTF-8 で表したときの長さ（`str::len` が返す値）です。

- `truncate_bytes` は、`s` の先頭部分のうち、`max` バイト以下で文字を分断しない最長のものを返します。
- `ellipsize` は、`s` が `max` バイト以下なら `s` のコピーを返します。そうでなければ、`truncate_bytes(s, max - 3)` の
  後ろに `'…'`（U+2026。UTF-8 で 3 バイト）を付けたものを返します。したがって、結果が `max` バイトを超えることは
  ありません。`max` は 3 以上です。
- `truncate_bytes` は、新しい文字列や文字列リテラルではなく、`s` 自身の一部、つまり `s` の先頭から始まる
  スライスを返します。結果が空のときも同じです。テストでは、返したスライスがどこを指しているかも確認します。
- `max` は、0 や `s` の長さより大きい値も含めて、どんな値も取り得ます（`max` が 3 以上でなければならないのは
  `ellipsize` だけです）。

### 例

| 呼び出し | 結果 |
| --- | --- |
| `truncate_bytes("héllo", 2)` | `"h"`（`é` は 2 バイトなので収まらない） |
| `truncate_bytes("héllo", 3)` | `"hé"` |
| `ellipsize("こんにちは", 10)` | `"こん…"`（6 + 3 = 9 バイト） |
| `ellipsize("hello!", 5)` | `"he…"` |
| `ellipsize("hello", 5)` | `"hello"` |
