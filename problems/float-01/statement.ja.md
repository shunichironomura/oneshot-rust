気象観測所が気温の測定値を `f64` で記録しています。センサーが故障したときは、気温の代わりに
NaN（非数）を記録します。測定値をまとめる 3 つの関数を実装してください。

```rust
pub fn max_reading(v: &[f64]) -> Option<f64>
pub fn sorted_readings(v: &[f64]) -> Vec<f64>
pub fn spread(v: &[f64]) -> Option<f64>
```

- 3 つの関数はどれも、NaN の測定値をすべて無視します。`-f64::NAN` のような負の NaN も無視します。
- 無限大は普通の測定値として扱います。`f64::INFINITY` はほかのどの測定値よりも大きく、
  `f64::NEG_INFINITY` はどれよりも小さい値です。
- `max_reading` は最大の測定値を返します。測定値が 1 つもなければ（スライスが空か、NaN しかなければ）
  `None` を返します。
- `sorted_readings` は測定値を昇順に並べて返します。等しい測定値もすべて残します。
- `spread` は最大の測定値から最小の測定値を引いた値を返します。引き算は普通の `f64` の引き算です
  （`f64` で表せないほど大きな結果は `f64::INFINITY` になります）。測定値が 1 つもなければ `None` です。

### 例

- `max_reading(&[1.5, f64::NAN, -2.0])` は `Some(1.5)`、`max_reading(&[f64::NAN])` は `None` です。
- `sorted_readings(&[3.0, f64::NAN, -1.0, 2.5])` は `[-1.0, 2.5, 3.0]` です。
- `spread(&[4.0, f64::NAN, 1.5])` は `Some(2.5)`、`spread(&[2.0])` は `Some(0.0)` です。
