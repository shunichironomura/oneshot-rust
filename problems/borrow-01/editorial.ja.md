`v.iter()` はループの間ずっと `v` を不変借用するので、その中で `v.push(...)`（可変借用）はできません。
**読み終えてから書き込む**のが基本です。追加する値をいったん別の `Vec` に集め、`extend` で後ろにつなげます。

### 別解

要素数をループの前に確定させ、インデックスでアクセスする方法もあります。`v[i]` の借用はその場で終わるので、
ループ本体で `push` しても問題ありません。

```rust
pub fn push_doubled(v: &mut Vec<i32>) {
    for i in 0..v.len() {
        if v[i] > 0 {
            v.push(v[i] * 2);
        }
    }
}
```

`0..v.len()` は最初に 1 回だけ評価されるので、追加した要素まではループしません。
