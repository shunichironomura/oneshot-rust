`Money` はセント単位の整数で金額を表す構造体です（エディタに入っています）。値札のように表示されるよう、
`Display` を実装してください。

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Money {
    pub cents: i64,
}

impl fmt::Display for Money { /* 実装する */ }
```

- 表示は `$`、ドル部分、`.`、ちょうど 2 桁のセント部分の順に並べます。`123456` セントは `$1,234.56`、
  `5` は `$0.05`、`0` は `$0.00` です。
- ドル部分は**右から** 3 桁ごとに `,` で区切ります。`.` の前には必ず 1 桁以上あり、
  先頭に余分な `0` は付けません。
- 負の金額は `$` の前に `-` を付けます。`-5` は `-$0.05` です。`i64::MIN` と `i64::MAX` を含め、
  すべての `i64` の値で正しく動く必要があります。
- 書式指定の幅・埋め文字・寄せ方には、文字列と同じように従います。
  - 幅が表示の文字数より大きいときは、ちょうど幅の文字数になるまで埋め文字（既定は空白）を足します。
    幅がないとき、または幅が表示の文字数以下のときは何も足しません。
  - `<` は左寄せ、`>` は右寄せ、`^` は中央寄せです。`^` で埋め文字を左右に均等に分けられないときは、
    余った 1 文字を右側に置きます。寄せ方の指定がないときは左寄せです。
- 精度や、`+`・`#`・`0` などのフラグは使いません。

### 例

| コード | 結果 |
| --- | --- |
| `Money { cents: 123456 }.to_string()` | `"$1,234.56"` |
| `format!("{}", Money { cents: -5 })` | `"-$0.05"` |
| `format!("{}", Money { cents: -100000000 })` | `"-$1,000,000.00"` |
| `format!("{:>10}", Money { cents: 5 })` | `"     $0.05"` |
| `format!("{:>8}", Money { cents: -100 })` | `"  -$1.00"` |
| `format!("{:*<9}", Money { cents: 5 })` | `"$0.05****"` |
| `format!("{:^11}", Money { cents: 5 })` | `"   $0.05   "` |
