宣言的マクロ（`macro_rules!`）を 3 つ書いてください。どれも、どんな入力でも受け付ける仮のルールとして
エディタに入っており、その後に、ほかのモジュールからパスで呼べるようにする `pub(crate) use` の行があります。
ルールを書き換え、`pub(crate) use` の行は残してください。

```rust
macro_rules! hashmap { /* ... */ }
pub(crate) use hashmap;

macro_rules! max_of { /* ... */ }
pub(crate) use max_of;

macro_rules! count { /* ... */ }
pub(crate) use count;
```

`hashmap!` は `std::collections::HashMap` を作ります。

- `hashmap! { k1 => v1, k2 => v2, ... }` は、これらのエントリを持つマップになります。キーと値には
  任意の式を書けます。末尾のカンマがあってもかまいません。
- `hashmap! {}` は空のマップになります。キーと値の型は、型注釈などの文脈から決まります。
- エントリは左から順に挿入します。そのため、同じキーが複数回出てくるときは最後の値が残ります。
- キーと値の式は、それぞれちょうど 1 回、`k1`、`v1`、`k2`、`v2`、... の順に評価します。

`max_of!` は引数のうち最大のものを返します。

- `max_of!(e1, e2, ...)` は同じ型 `T` の式を 1 つ以上受け取り、それらの値のうち最大のものになります。
  比較には `PartialOrd` を使います。`T` は `Copy`、`Clone`、`Ord` を実装しているとは限りません
  （NaN のように比較できない値をテストで渡すことはありません）。
- 最大の値と等しい引数が複数あるときは、そのうち最も左のものが結果になります。
- 各引数はちょうど 1 回、左から順に評価します。末尾のカンマがあってもかまいません。

`count!` はトークンツリーを数えます。

- `count!(...)` は、入力に含まれるトークンツリーの数を `usize` で表したものになります。
  `const N: usize = count!(...);` や配列の長さに使える定数式でなければなりません。
- トークンツリーとは、1 つのトークン（識別子、リテラル、ライフタイム、または `+`、`,`、`::`、`=>` などの
  記号）か、`()`、`[]`、`{}` で囲まれたグループ（中身全体を含む）のことです。`count!()` は `0` です。

テストは各マクロを `crate::user::max_of!(3, 9, 4)` のようにパスで呼び出します。呼び出すのは別のモジュールで、
そこにはマクロにも `HashMap` にも `use` 宣言がありません。

### 例

```rust
let m: std::collections::HashMap<&str, i32> = crate::user::hashmap! { "a" => 1, "b" => 2, };
// m のエントリは 2 つで、m["b"] は 2

let x: i32 = crate::user::max_of!(3, 9, 4); // 9

const N: usize = crate::user::count!(a + (b c)); // 3：`a`、`+`、`(b c)`
const Z: usize = crate::user::count!(); // 0
```
