`std::collections::HashMap` を作る宣言的マクロ（`macro_rules!`）`hashmap!` を書いてください。
マクロは、どんな入力でも受け付ける仮のルールとしてエディタに入っており、その後に、ほかのモジュールから
パスで呼べるようにする `pub(crate) use` の行があります。ルールを書き換え、`pub(crate) use` の行は残してください。

```rust
macro_rules! hashmap { /* ... */ }
pub(crate) use hashmap;
```

- `hashmap! { k1 => v1, k2 => v2, ... }` は、これらのエントリを持つマップになります。キーと値には
  任意の式を書けます。末尾のカンマがあってもかまいません。
- `hashmap! {}` は空のマップになります。キーと値の型は、型注釈などの文脈から決まります。
- エントリは左から順に挿入します。そのため、同じキーが複数回出てくるときは最後の値が残ります。
- キーと値の式は、それぞれちょうど 1 回、`k1`、`v1`、`k2`、`v2`、... の順に評価します。

テストはマクロを `crate::user::hashmap!` とパスで呼び出します。呼び出すのは別のモジュールで、
そこにはマクロにも `HashMap` にも `use` 宣言がありません。

### 例

```rust
let m: std::collections::HashMap<&str, i32> = crate::user::hashmap! { "a" => 1, "b" => 2, };
// m のエントリは 2 つで、m["b"] は 2
```
