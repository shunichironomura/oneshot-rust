次のコードはコンパイルが通りません。**エラーメッセージを見ずに**、どこで怒られるかを予想して直してください。

`Labels` は id に対してラベル `"item-<id>"` を返します。ラベルを作るのは重い処理だという想定なので、
各ラベルは**一度だけ**作ってキャッシュに保存し、以降はキャッシュ内のラベルへの参照を返します。
`built` は、これまでにラベルをいくつ作ったかを返します。

```rust
impl Labels {
    pub fn new() -> Labels
    pub fn get(&mut self, id: u32) -> &str
    pub fn built(&self) -> usize
}
```

これらのシグネチャは変えないでください。

### 例

`get(3)` を 2 回呼ぶとどちらも `"item-3"` を返し、そのあとの `built()` は `1` です。
