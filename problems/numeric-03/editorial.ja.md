`/` は 0 の方向に丸め、`%` はそれに対応する余りを返すので、余りの符号は割られる数と同じになります。
`-1 % 5` は `-1` で、これを `as usize` すると巨大な数になります。`rem_euclid` は余りが負にならないように
選ぶので、割る数が正なら `0..len` の範囲の余りになります。

`(i + n) % n` のように先に `len` を足して負の余りを直そうとしても足りません。`i < -n` のときはまだ負になり、
ジャッジはデバッグビルドと同じくオーバーフロー検査を有効にしてビルドするので、`i64::MAX + n` は
パニック（`attempt to add with overflow`）します。

### 別解

`rem_euclid` を使わない場合は、`i` ではなく余りに `n` を足し、もう一度余りを取ります。

```rust
pub fn wrap_index(i: i64, len: usize) -> usize {
    let n = len as i64;
    // `i % n` は `-n` より大きく `n` より小さいので、`n` を足してもオーバーフローしない
    ((i % n + n) % n) as usize
}
```
