5 つのクロージャは似ていますが、受け取る型はすべて同じではありません。`&` の数を数えてみましょう。

- `v.iter()` は `&i32` を返します。`words.iter()` は `&&str` や `&String` を返します。
- `find` と `filter` は、クロージャで判定した後も要素を使います（返したり、次に渡したりします）。
  そのためクロージャには**要素への参照**が渡されます。`v.iter()` なら `&&i32` です。
- `position`、`any`、`map` は呼び出しの後は要素を使わないので、クロージャには要素そのものが渡されます。
  `v.iter()` なら `&i32`、`words.iter()` なら `&String` です。

コンパイルが通るかどうかは、それぞれの本体が引数をどう使うかで決まります。

- 演算子は自動で参照外しをせず、実装されている型にしか使えません。`x < 0` は `&&i32` と整数を
  比べています（E0308）。`|&&x|` や `**x` と書けば `i32` まで降りられます。
- `find` は見つけた要素を返すので、結果は `Option<i32>` ではなく `Option<&i32>` です。`copied()` は
  `&i32` の要素を `i32` に変えます（`i32` は `Copy` です）。`iter()` の直後で呼べば、クロージャが受け取る
  参照が 1 段減り、結果もただの `i32` になるので、両方の問題が一度に解決します。このときクロージャが
  受け取るのは `&i32` で、`<` は両辺が同じ型でなければならないので、`|&x|` と書いています。
- `position_of_max` の `x == max` は `&i32` どうしを比べているので問題ありません。
- メソッド呼び出しは、演算子と違って自動で参照外しをします。`count_long` のクロージャは `&&&str` という 3 重の参照を
  受け取りますが、`w.len()` はちゃんと `str::len` を見つけます。つまり `position_of_max` と `count_long` は
  最初から正しかったのです。
- `slice::contains` は `&T`、ここでは `&String` を受け取るので、`&str` は渡せません（E0308）。`==` はもっと柔軟で、
  `String` と `str` は比べられるので、`s: &String` と `w: &str` に対して `s == w` と書けます。
  `==` での比較は単語全体が一致するときだけ真になります。一部を探す `s.contains(w)` とは違います。
- パターン `|&w|` は参照の中から `String` を取り出そうとするので、ムーブになってしまいます（E0507）。
  同じパターンが `i32` で使えるのは、`i32` が `Copy` だからです。`|w|` で受け取って、そのままメソッドを呼びます。

### 別解

テンプレートの形を残したまま、クロージャの中でパターンや `*` を使って参照を外し、最後に結果をコピーする方法です。
メソッドを呼ぶだけのクロージャは、`String::len` のようなメソッドのパスで置き換えられます。

```rust
pub fn first_negative(v: &[i32]) -> Option<i32> {
    v.iter().find(|&&x| x < 0).copied()
}

pub fn contains_word(words: &[String], w: &str) -> bool {
    words.iter().any(|s| s.as_str() == w)
}

pub fn total_len(words: &[String]) -> usize {
    words.iter().map(String::len).sum()
}
```

`words.contains(&w.to_string())` でも動きますが、比べるためだけに新しい `String` を作ることになります。

普通の `for` ループを使えば、参照が何重かを気にせずに済みます。`for &x in v` は、スライスから
`i32` を 1 つずつコピーします。

```rust
pub fn first_negative(v: &[i32]) -> Option<i32> {
    for &x in v {
        if x < 0 {
            return Some(x);
        }
    }
    None
}
```
