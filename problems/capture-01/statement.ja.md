次のコードはコンパイルが通りません。直してください。

`fill_squares` は、`out` の各要素をその添字の 2 乗にします。処理は `workers` 個のスレッドで分担し、
ワーカー `w` は添字 `w`、`w + workers`、`w + 2 * workers`、… の要素を書き込みます。

```rust
pub fn fill_squares(out: &mut [u64], workers: usize)
```

- `fill_squares` から戻った時点で、`out` のすべての添字 `i` について `out[i]` は `i * i` です。
  元の値が何であっても上書きします。添字は `out` の先頭から数えます（`out` がもっと大きなスライスの
  一部であっても同じです）。
- `workers` は 1 以上で、`out.len()` より大きいこともあります。その場合、書き込む要素がない
  ワーカーもあります。`out` が空のこともあります。
- `fill_squares` から戻る前に、すべてのスレッドが終わっていなければなりません。

シグネチャは変えないでください。処理は別々のスレッド（`workers` 個以下）で分担したままにしてください。
ただし、要素の割り振り方は変えても構いません。`unsafe` のコードを残しても構いません。

### 例

```rust
let mut v = [7; 5];
fill_squares(&mut v, 2);
// v は [0, 1, 4, 9, 16] になる。ワーカー 0 が添字 0, 2, 4 を、ワーカー 1 が添字 1, 3 を書き込む。
```
