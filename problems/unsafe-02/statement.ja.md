次のコードはコンパイルが通り、手元で実行するとテストにもすべて通ります。
しかし**未定義動作**（UB）を含んでおり、Miri で実行すると UB として検出されます。

`split_in_two` は可変スライスを添字 `mid` で分け、`v[..mid]` と `v[mid..]` の 2 つの可変スライスを返します。
呼び出し側は両方を同時に読み書きします。`mid <= v.len()` と仮定してかまいません。

```rust
pub fn split_in_two(v: &mut [i32], mid: usize) -> (&mut [i32], &mut [i32])
```

UB を取り除いて、正しく動くようにしてください（`unsafe` を使い続けてもかまいません）。

### 例

`v = [1, 2, 3, 4, 5]`、`mid = 2` のとき、2 つの半分は `[1, 2]` と `[3, 4, 5]` です。
`left[0] = 10`、`right[0] = 30` と書き込むと、`v` は `[10, 2, 30, 4, 5]` になります。
