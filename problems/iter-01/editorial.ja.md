`v.iter()` は `&i64` を返し、`filter` は要素への参照をクロージャに渡すので、引数は `&&i64` になります。
`|&&x|` というパターンで参照を 2 段はがしています。`sum()` は返り値の型から `i64` を作ればよいと推論されます。

`x % 2 == 0` は負の数でも正しく判定できます（`-4 % 2 == 0`）。奇数を `x % 2 == 1` で判定すると
`-3 % 2 == -1` なので誤ります。

### 別解

`copied()` で要素を `i64` の値に変えると、クロージャが簡単になります。

```rust
pub fn sum_even_squares(v: &[i64]) -> i64 {
    v.iter().copied().filter(|x| x % 2 == 0).map(|x| x * x).sum()
}
```
