それぞれの型が何回使われたかを数えたいプログラムがあります。プログラム全体で**型ごとに** 1 つの
カウンタを持つ、4 つの関数を実装してください。

```rust
pub fn register<T: 'static>() -> usize;
pub fn count<T: 'static>() -> usize;
pub fn total() -> usize;
pub fn distinct() -> usize;
```

- `register::<T>()` は型 `T` のカウンタに 1 を足し、そのカウンタの新しい値を返します。ある型の
  最初の `register::<T>()` は `1` を返します。
- `count::<T>()` は `T` のカウンタの値を返します。一度も登録されていない型なら `0` です。
  何も変更しません。特に、`T` を登録することはありません。
- `total()` は、これまでに `register` が呼ばれた回数を、すべての型について合計して返します
  （すべてのカウンタの和）。
- `distinct()` は、1 回以上登録された型が何種類あるかを返します。
- 型ごとに別々のカウンタを持ちます。型の区別は Rust での型の区別とまったく同じです。
  型エイリアスは、それが指す型と同じ型です。`Vec<u8>` と `Vec<u16>` は別の型です。
  別々の場所で宣言された 2 つの構造体は、名前が同じでも別の型です。
- カウンタはプログラム全体で共有され、プログラムが終わるまで保持されます。リセットされることは
  ありません。これらの関数は複数のスレッドから同時に呼ばれることがあり、すべてのスレッドが同じ
  カウンタを共有します。どの呼び出しも漏れなく数えられ、同じ型についての呼び出しが同じ値を
  返すことはありません。`register::<T>()` を `n` 回呼ぶと、返り値は順不同でちょうど
  `1`、`2`、...、`n` です。

ハーネスはテストケースの中で独自の型（`struct Apple;` のようなユニット構造体）を宣言して使うほか、
`Vec<u8>` などの標準の型も使います。シグネチャは変えないでください。

### 例

まだ何も登録していないプログラムでは、次のようになります。

```rust
struct Apple;
struct Pear;
struct Plum;

register::<Apple>(); // 1
register::<Apple>(); // 2
register::<Pear>();  // 1
count::<Apple>();    // 2
count::<Plum>();     // 0
total();             // 3
distinct();          // 2
```

型エイリアスは新しい型ではありません。`Vec<u8>` と `Vec<u16>` がまだ登録されていなければ、
次のようになります。

```rust
type Bytes = Vec<u8>;

register::<Vec<u8>>();  // 1
register::<Bytes>();    // 2（Bytes は Vec<u8> と同じ型）
register::<Vec<u16>>(); // 1
```
