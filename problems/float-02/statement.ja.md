次のコードはコンパイルが通り、手元で実行すると「それっぽく」動くこともあります。
しかし**未定義動作（UB）**を含んでおり、Miri で実行すると UB として検出されます。

`to_levels` は、明るさのサンプルを 0 から 255 までの 8 ビットの色の段階（レベル）に変換します。
サンプル 1 つにつきレベルを 1 つ、同じ順に並べて返します。

```rust
pub fn to_levels(samples: &[f32]) -> Vec<u8>
```

- サンプル `s` のレベルは `(s * 255.0).round()` です。`round` は `f32::round` で、ちょうど半分のときは
  0 から遠い方に丸めます。たとえば `0.5` は `127.5` になり、丸めて `128` になります。
- 0 未満のレベルは 0 に、255 を超えるレベルは 255 にします。NaN のサンプルは 0 にします。
- サンプルが `0.0..=1.0` に収まっているとは**限りません**。負の値、1 より大きい値、無限大、NaN も
  ありえます。

UB を取り除いて、どんな入力でも正しく動くようにしてください（`unsafe` を使い続けてもかまいません）。

### 例

`to_levels(&[0.0, 0.5, 1.0, 1.5, -0.2, f32::NAN, f32::INFINITY])` は
`[0, 128, 255, 255, 0, 0, 255]` を返します。
