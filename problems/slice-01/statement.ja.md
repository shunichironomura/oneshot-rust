スライスを増加する連なりに分ける関数 `rising_runs` を実装してください。

```rust
pub fn rising_runs(v: &[i32]) -> Vec<&[i32]>
```

- `rising_runs` は `v` を、狭義単調増加の（右の要素がつねに左の要素より大きい）連なりに
  できるだけ長く分けます。直前の要素以下の要素があるたびに、そこから新しい連なりが始まります。
  連なりは `v` の部分スライスとして、左から順に返します。
- `v` の長さは 0 や 1 も含めていくつでもよく、値は `i32::MIN` や `i32::MAX` も含めてどの `i32` でも
  かまいません。パニックしてはいけません。`v` が空なら、空のベクタを返します。

### 例

`rising_runs(&[1, 2, 2, 3, 1])` は `[[1, 2], [2, 3], [1]]` です。2 つ目の `2` は 1 つ目の `2` より
大きくないので、そこから新しい連なりが始まります。
