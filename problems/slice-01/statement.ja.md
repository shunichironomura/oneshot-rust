スライスのとなり合う要素を調べる関数を 4 つ実装してください。等しい値の連なり、増加する連なり、
山、ペアを求めます。

```rust
pub fn runs(v: &[i32]) -> Vec<(i32, usize)>
pub fn rising_runs(v: &[i32]) -> Vec<&[i32]>
pub fn local_peaks(v: &[i32]) -> Vec<usize>
pub fn pairs(v: &[i32]) -> (Vec<(i32, i32)>, Option<i32>)
```

- `runs` は `v` を、等しい値が続くグループにできるだけ長く分け、各グループの `(値, 長さ)` を
  左から順に返します。等しい値でも、となり合っていなければ別のグループです。
- `rising_runs` は `v` を、狭義単調増加の（右の要素がつねに左の要素より大きい）連なりに
  できるだけ長く分けます。直前の要素以下の要素があるたびに、そこから新しい連なりが始まります。
  連なりは `v` の部分スライスとして、左から順に返します。
- `local_peaks` は山の位置、つまり `v[i - 1] < v[i]` かつ `v[i] > v[i + 1]` となるすべての
  添字 `i` を昇順で返します。先頭と末尾の要素は片側にとなりがないので、山にはなりません。
  平らな頂上も山ではありません。たとえば `[1, 4, 4, 1]` に山はありません。
- `pairs` は `v` を先頭から、重ならないペア `(v[0], v[1])`、`(v[2], v[3])`、… に分けます。
  `v` の長さが奇数なら最後の要素が余るので、それを `Some` に入れて返します。そうでなければ
  結果の 2 つ目は `None` です。
- `v` の長さは 0、1、2 も含めていくつでもよく、値は `i32::MIN` や `i32::MAX` も含めてどの `i32` でも
  かまいません。どの関数もパニックしてはいけません。`v` が空なら、結果のベクタはどれも空で、
  `pairs` は `(vec![], None)` を返します。

### 例

- `runs(&[1, 1, 2, 3, 3, 3])` は `[(1, 2), (2, 1), (3, 3)]` です。
- `rising_runs(&[1, 2, 2, 3, 1])` は `[[1, 2], [2, 3], [1]]` です。2 つ目の `2` は 1 つ目の `2` より
  大きくないので、そこから新しい連なりが始まります。
- `local_peaks(&[1, 3, 2, 5, 1])` は `[1, 3]` です（`3` と `5` の位置）。
- `pairs(&[1, 2, 3, 4, 5])` は `([(1, 2), (3, 4)], Some(5))` です。
