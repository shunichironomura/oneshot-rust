小さな店では、1 行の文字数が決まったプリンタでレシートを印刷しています。
文字を並べるための 4 つの関数を実装してください。

```rust
pub fn receipt_line(name: &str, qty: u32, price: f64) -> String
pub fn hex_color(r: u8, g: u8, b: u8) -> String
pub fn bits(n: u8) -> String
pub fn table_row(cells: &[&str], width: usize) -> String
```

- `receipt_line` は、次の部品をこの順に、間に何も入れずにつなげます。
  1. `name` を 10 文字の欄に左寄せしたもの（右側を空白で埋めます）。10 文字より長い名前は、
     先頭の 10 文字に切り詰めます。
  2. 空白 1 つ。
  3. `qty` を 3 文字の欄に右寄せしたもの（左側を空白で埋めます）。欄に収まらない数は、
     すべての桁をそのまま出力します。
  4. `" x "`（空白、`x`、空白）。
  5. `price` を小数第 2 位までの最も近い値に丸め、小数点以下を必ずちょうど 2 桁で書いたものを、
     8 文字の欄に右寄せしたもの。欄に収まらないときは、そのまま全体を出力します。`price` は有限で
     0 以上です。また、丸め先の候補 2 つのちょうど中間の値になることはありません。
- `hex_color` は、`#` の後に `r`、`g`、`b` をこの順に、それぞれちょうど 2 桁の大文字の 16 進数で
  並べた文字列を返します。
- `bits` は、`0b` の後に `n` をちょうど 8 桁の 2 進数で書いた文字列を返します。
- `table_row` は、各セルを `width` 文字の欄の中央に置き、残りを空白で埋めます。空白を左右に均等に
  分けられないときは、余った 1 つを右側に置きます。`width` より長いセルは、空白を足さずにそのまま
  出力します。各セルの前に `|` を置き、行の最後にもう 1 つ `|` を置きます。そのため、
  セルが 1 つもない行は `|` だけになります。
- 文字列はすべて ASCII です。

### 例

```rust
receipt_line("Coffee", 2, 3.5)               // "Coffee       2 x     3.50"
receipt_line("Chocolate bar", 12, 1234.567)  // "Chocolate   12 x  1234.57"
hex_color(128, 255, 90)                      // "#80FF5A"
bits(5)                                      // "0b00000101"
table_row(&["a", "bb"], 4)                   // "| a  | bb |"
```
