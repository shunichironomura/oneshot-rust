`Vec2<T>` は、成分に任意の数値型を使える 2 次元ベクトルです。普通の演算子でベクトルの計算ができるようにしてください。
ハーネスは整数（`i32`, `i64`）と浮動小数点数（`f32`, `f64`）で使います。

| コード | 結果 |
| --- | --- |
| `a + b` | `Vec2 { x: a.x + b.x, y: a.y + b.y }` |
| `a += b` | `a = a + b` と同じ |
| `a * k`（`k: T`） | `Vec2 { x: a.x * k, y: a.y * k }` |
| `-a` | `Vec2 { x: -a.x, y: -a.y }` |
| `a.dot(b)` | `a.x * b.x + a.y * b.y` |

`template.rs` には `impl` ブロックの枠が用意してあります。`Vec2` の定義は変更しないでください。
それ以外は必要に応じて変更してかまいません。

### 例

`a = Vec2::new(1, 2)`、`b = Vec2::new(3, -4)` のとき、`a + b` は `Vec2::new(4, -2)`、`a * 3` は
`Vec2::new(3, 6)`、`-b` は `Vec2::new(-3, 4)`、`a.dot(b)` は `-5` です。

`let mut p = Vec2::new(0.5, 1.0); p += Vec2::new(0.25, -2.0);` のあと、`p` は `Vec2::new(0.75, -1.0)`、
`-(p * 2.0)` は `Vec2::new(-1.5, 2.0)` です。
