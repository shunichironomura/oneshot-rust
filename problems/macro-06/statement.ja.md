トークンツリーを数える宣言的マクロ（`macro_rules!`）`count!` を書いてください。マクロは、どんな入力でも
受け付ける仮のルールとしてエディタに入っており、その後に、ほかのモジュールからパスで呼べるようにする
`pub(crate) use` の行があります。ルールを書き換え、`pub(crate) use` の行は残してください。

```rust
macro_rules! count { /* ... */ }
pub(crate) use count;
```

- `count!(...)` は、入力に含まれるトークンツリーの数を `usize` で表したものになります。
  `const N: usize = count!(...);` や配列の長さに使える定数式でなければなりません。
- トークンツリーとは、1 つのトークン（識別子、キーワード、リテラル、ライフタイム、または `+`、`,`、`::`、
  `=>` などの記号）か、`()`、`[]`、`{}` で囲まれたグループ（中身全体を含む）のことです。`count!()` は `0` です。

テストはマクロを `crate::user::count!` とパスで呼び出します。呼び出すのは別のモジュールで、
そこにはマクロの `use` 宣言がありません。

### 例

```rust
const N: usize = crate::user::count!(a + (b c)); // 3：`a`、`+`、`(b c)`
const Z: usize = crate::user::count!(); // 0
```
